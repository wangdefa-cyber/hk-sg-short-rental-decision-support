## 保留为研究限制、不作结果修改

- Gini 使用离散样本近似式；与无偏公式差异约 0.0005 和 0.0009。
- K-Means 轮廓系数 HK=0.312、SG=0.241，属于弱至中等结构，定位为描述性分群。
- DBSCAN 参数未做完整网格搜索，已在算法文档注明敏感性。
- 供需指数采用等权百分位综合；增长缺失按 0 处理，属于探索性设定。
- 相关分析未做多重比较校正，报告和页面均注明相关不等同因果。
- Power BI 和 Gephi 不虚构成品文件；保留 CSV/DAX 和 GEXF/节点边表交付。
