# 数据字典

## 1. 数据源

### Inside Airbnb

- 香港快照：2026-09-20
- 新加坡快照：2026-09-23
- 许可：CC BY 4.0
- 原始文件：`listings.csv.gz`、`calendar.csv.gz`、`reviews.csv.gz`、`neighbourhoods.csv`、`neighbourhoods.geojson`
- 原始文件只读，详细信息见 `data_manifest.json`

### Google Trends

- 用途：旅游、Airbnb 与住宿搜索关注度的外部代理变量
- 当前状态：已导入 8 个真实导出文件
- 指标范围：0–100 的相对搜索兴趣指数，不是绝对搜索量

## 3. 事实表

### fact_listing_snapshot

一套房源在快照日期上的经营指标。

| 字段 | 含义 |
|---|---|
| listing_key | 跨城市唯一房源键 |

| price_clean | 剔除本城市、同房型 1%–99% 极端值后的价格 |
| price_p01 / price_p99 | 城市与房型内的价格筛选边界 |
| price_outlier | 是否被判为价格异常 |
| price_per_guest | `price_clean / accommodates` |
| price_per_bedroom | `price_clean / bedrooms` |
| quote_currency | 从价格报价 JSON 提取的币种 |
| quote_is_monthly_priced | 报价是否采用月租定价 |
| availability_30/60/90/365 | 未来不同窗口可订天数 |
| number_of_reviews | 历史评论数 |
| number_of_reviews_ltm | 最近 12 个月评论数 |
| number_of_reviews_l30d | 最近 30 天评论数 |
| review_scores_rating | 综合评分 |
| reviews_per_month | 原始字段的月均评论数 |
| occupancy_estimate_raw | 原始估计入住指标 |
| occupancy_estimate_valid | 仅在 [0,1] 范围内的估计值 |
| estimated_revenue_l365d | 原始估计年收入 |
| is_entire_home | 是否整套房源 |
| is_private_room | 是否独立房间 |
| minimum_nights_invalid | 最低入住天数是否非法 |
| availability_365_invalid | 可订天数是否超出 0–365 |

### fact_calendar

一个房源一天一行。

| 字段 | 含义 |
|---|---|
| listing_key | 房源键 |
| date | 日期 |
| year_month | 年月 |
| weekday / is_weekend | 星期属性 |
| available | 当天是否可订 |
| available_int | 可订状态整数表示，用于聚合 |
| minimum_nights / maximum_nights | 当天限制 |

注意：`available` 不等于实际入住状态。不可订可能是已被预订，也可能是房东主动关闭日历。

|---|---|

### fact_google_trends

当前包含 7 条真实月度序列，共 427 条观测。

| 字段 | 含义 |
|---|---|
| city_key | hong-kong、singapore 或 global |
| city_name | 城市中文名或“全球” |
| keyword_group | tourism、accommodation、airbnb |
| keyword | 单一搜索关键词 |
| year_month | 年月 |
| date | 月度日期（当月第一天） |
| interest_index | Google Trends 独立导出的 0–100 相对搜索兴趣 |
| z_score | 每条序列独立计算的标准化值 |
| relative_to_first | 相对该序列首月的指数 |
| mom_change_pct | 月度变化率 |
| source_file | 源 CSV 文件 |
| query_region | Worldwide |
| export_scale | 独立导出说明 |

`google_trends_top_queries.csv` 单独保存全球 Airbnb 相关搜索词、搜索兴趣和变化百分比。

## 4. 清洗规则摘要

- 价格转数值，保留原值和清洗值。
- 价格异常按城市 × 房型 1%–99% 分位识别，不做删除。
- 坐标按城市经纬度合理范围校验。
- 评分缺失保留，不填 0。
- 评论按评论 ID 去重，并保留去重日志。
- 房源 ID 必须使用 `city_key + listing_id` 组合，不能跨城市直接连接。
