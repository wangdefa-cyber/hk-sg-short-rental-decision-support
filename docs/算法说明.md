# 算法说明

## 1. 价格清洗

- 原始价格从字符串中解析为数值。
- 异常值按“城市 × 房型”1% 和 99% 分位识别。
- 保留原始价格，额外生成 `price_outlier` 和 `price_clean`。
- `price_clean` 仅用于描述统计和模型分析，不修改原始文件。

## 2. K-Means 经营类型聚类

目标函数：

```text
J = Σ_k Σ_{x_i∈C_k} ||x_i - μ_k||²
```

特征经过中位数缺失填补和标准化，候选 k 为 2–8。使用 Silhouette Score 选择聚类数：

```text
s(i) = (b(i) - a(i)) / max(a(i), b(i))
```

- 香港：k=5，Silhouette=0.3120
- 新加坡：k=4，Silhouette=0.2414
- 聚类标签在查看真实画像后解释，不预先指定经营类型。

## 3. 房价模型

目标变量：

```text
y = log(1 + price_clean)
```

分别对两个城市建模，避免 HKD 与 SGD 直接混合。候选特征包括容量、卧室、床位、卫浴、最低入住天数、评论数、评分、可订天数、房东房源数、房型和社区。

模型：

1. 多元线性回归
2. 随机森林回归，400 棵树，min_samples_leaf=5，max_features=0.7

评价指标：

```text
R² = 1 - SSE / SST
MAE = mean(|y_i - ŷ_i|)
RMSE = sqrt(mean((y_i - ŷ_i)²))
```

随机森林在香港和新加坡均优于线性回归。模型解释的是挂牌价格统计关联，不是成交价或因果效应。

## 4. DBSCAN 空间聚类

- 坐标先转为弧度。
- 使用 Haversine 距离。
- eps = 0.5 km，min_samples = 20。
- 噪声点保留，不强制归类。

香港得到 11 个簇、511 个噪声点；新加坡得到 10 个簇、583 个噪声点。eps 与 min_samples 使用固定研究设定，结果应结合参数敏感性解释。

## 5. HHI 与 Gini

房东层面的 HHI：

```text
HHI = Σ_i s_i² × 10000
```

其中 `s_i` 为房东 i 的房源占全部房源的比例。Gini 用于描述房东房源数量的不均衡程度。

本项目采用常用的离散样本 Gini 近似式；与无偏公式相比，香港和新加坡的差异约为 0.0005 和 0.0009，对结论没有实质影响。HHI 和 Gini 仅描述平台公开房源的集中程度，不代表真实市场垄断。

## 6. 社区供需匹配模型

供给侧使用城市内百分位指数：

- 房源密度
- 房源数量
- 未来可订率
- 房东竞争程度
- 价格可负担性（价格越低，供给可及性越高）

需求侧代理：

- 最近 12 个月每房源评论数
- 最近 12 个月评论总量
- 评论增长率

供需指数：

```text
S = mean(supply_component_ranks)
D = mean(demand_component_ranks)
M = D / (S + ε)
```

四象限以城市内部 S、D 中位数划分：

- 高需求、高供给：竞争成熟区
- 高需求、低供给：潜在机会区
- 低需求、高供给：供给压力区
- 低需求、低供给：谨慎观察区

该指数采用等权综合和城市内百分位，是研究性相对指标，不是真实订单供需比或投资收益率。`competition_rank` 实际衡量房东碎片化程度；评论增长在缺少前 12 个月数据时按 0 处理，因此供需分型应结合样本量做敏感性解读。

## 7. 经营决策规则

决策中心使用：

- 同城市、同社区、同房型和相近容量的可比房源
- 价格中位数和四分位区间
- 评分和评论活动
- 社区供需指数
- 房东集中度和竞争程度

建议价格区间由可比房源中位价乘以容量调整系数和经营定位系数得到。上述系数用于课程场景下的可解释演示，未经订单数据校准，因此不能视为统计定价结论。所有建议都列出输入指标和预警条件。

## 8. Google Trends 标准化与相关分析

真实数据包括 7 条单关键词月度序列（427 条观测）和 1 个全球相关搜索词表。由于每个 CSV 独立归一化，原始 0–100 指数不能跨文件比较。分析步骤：

1. 解析日期和单一关键词列；
2. 将每条序列转为 z-score：
   z = (x - mean(x)) / SD_population(x)；
3. 计算首尾三个月均值、线性斜率、峰值、低谷和完整年份季节性；
4. 使用一阶月度变化计算评论活动相关，降低共同趋势导致的虚假高相关；
5. 使用同一 z-score 方法比较香港和新加坡的月度变化；
6. 对 Airbnb 相关搜索词按搜索兴趣排序。

相关系数只表示统计关联，不代表因果，也不能解释为订单量或入住率。
