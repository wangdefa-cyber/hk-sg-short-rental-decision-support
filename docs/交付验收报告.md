## 10. 已知限制

- Google Trends 各文件独立归一化，原始 0–100 指数不能跨文件直接比较。
- 评论数量是需求活动代理，不是订单量或入住人数。
- 未来日历可订状态不等于真实入住率。
- K-Means 轮廓系数属于弱至中等结构，经营类型定位为描述性分群。
- 项目未附原生 `.pbix` 文件或 Gephi 工程截图，提供可复现的 CSV、DAX 说明和 GEXF/节点边表。
- PDF 自动导出依赖 Windows 和 Microsoft Word；其他系统可使用已交付 PDF，但重导 PDF 需调整环境。
- 本机浏览器自动化受系统策略限制，未能完成自动截图式视觉验收；页面功能由 Streamlit AppTest 覆盖，最终视觉效果需按下方步骤人工确认。

## 11. 人工验收步骤

1. 运行 `.\.venv\Scripts\streamlit.exe run app.py`，打开 `http://localhost:8501`。
2. 检查侧边栏是否显示香港、新加坡日期范围，以及 Google Trends 已更新状态。
3. 进入“市场供给分析”，切换香港/新加坡并组合社区、房型和价格筛选，确认指标和图表同步变化。
4. 进入“供需匹配分析”，清空市场类型，确认出现提示而不是空图或报错。
5. 进入“经营决策中心”，生成一次建议后切换城市，确认旧建议消失并提示重新生成。
6. 进入“研究报告中心”，下载 DOCX、PDF、Excel 和 ECharts 看板，确认文件可打开。
7. 在 1366×768 和 1920×1080 窗口下检查侧边栏、表格、图表和中文显示。
