# 项目实施计划（阶段 A）

## 1. 审查结论

项目目录原本只有课程中期报告模板。现已建立基础工程目录，并下载香港、新加坡的 Inside Airbnb 最新快照。

| 城市 | 快照日期 | 房源 | 日历记录 | 评论 | 社区边界 |
|---|---:|---:|---:|---:|---:|
| 香港 | 2026-09-20 | 6,614 | 2,414,110 | 122,715 | 18 |
| 新加坡 | 2026-09-23 | 3,208 | 1,170,950 | 46,000 | 55 |

原始数据均已记录 SHA256、来源 URL、下载日期和快照日期，清单位于 `data_manifest.json`。

## 2. 当前缺口

1. Google Trends：已导入 8 个真实导出文件，7 条月度序列共 427 条观测，无缺失值。
2. 城市背景数据：人口、面积、访客量、酒店入住率尚待补充。
3. Python 环境：基础环境存在 NumPy 与旧版 PyArrow 的兼容问题；GeoPandas、Shapely、WordCloud 等依赖未安装。
4. 报告：原模板为旧版 `.doc`，后续将保留原文件并生成 `.docx` 副本。

## 3. 数据质量发现

- 香港价格缺失 1,011 条（15.3%），新加坡价格缺失 480 条（15.0%）。
- 两城 `bathrooms` 字段全部为空，需要改用 `bathrooms_text` 解析。
- 新加坡 `license` 缺失 45.9%，香港 `license` 全部为空，不能据此判断合规性。
- 香港 `estimated_occupancy_l365d` 最大值 255，必须核查字段定义并清洗。
- 日历只覆盖未来约一年，`available` 不能当作历史入住率。
- 评论时间跨度长，可做趋势和文本分析，但评论数量不能等同于订单量。
- 香港与新加坡快照相差三天，跨城市比较必须声明时间差。

## 4. 实施路线

### 阶段 A：项目审查

- 完毕：目录、数据、模板、文件哈希、基础质量检查。
- 进行中：依赖环境修复和报告模板副本。
- 输出：`docs/数据审查报告.md`、`data_manifest.json`、本计划。

### 阶段 B：数据工程

- 读取房源、日历、评论和 GeoJSON。
- 清洗价格、日期、房型、经纬度、异常值和缺失值。
- 构建 `dim_city`、`dim_listing`、`dim_neighbourhood`、`dim_date`、`fact_listing_snapshot`、`fact_calendar`、`fact_review`。
- 输出 Parquet 和 SQLite。
- 建立数据字典与清洗日志。
- 导入 Google Trends 与城市背景数据。

### 阶段 C：数据挖掘

- 描述统计与城市对比。
- 空间分析和 DBSCAN 聚类。
- 线性回归与随机森林房价模型。
- K-Means 经营类型聚类。
- 房东集中度、HHI、Gini 和 Lorenz 曲线。
- Google Trends 趋势、相关性和滞后相关。
- 社区供需匹配指数与四象限。
- 可解释的经营决策推荐规则。

### 阶段 D：结果验证

- 固定随机种子。
- 保存训练/测试划分、模型参数、指标和数据版本。
- 增加缺失数据、极端值和空筛选结果测试。
- 每条经营建议必须能追溯到具体指标。

### 阶段 E：决策支持系统

- Streamlit 中文界面，共 8 个页面。
- 筛选器必须影响图表；外部数据按实际导入状态展示。
- 数据管理页支持上传 CSV、CSV.GZ 和 GeoJSON。

### 阶段 F：课程成果

- Excel 多维分析文件。
- Power BI 数据源与 DAX 说明。
- Gephi GEXF/节点/边文件。
- ECharts 交互图表。
- 香港与新加坡词云。
- Word 报告草稿和图表素材。

### 阶段 G：最终验收

- 数据、模型、供需匹配和系统测试全部通过。
- 检查所有交付物真实存在并可由 README 复现。
- 不宣称未完成的功能已经完成。

## 5. 优先级

1. 修复 Python 依赖环境。
2. 完成数据清洗、统一字段、Parquet/SQLite 数据仓库。
3. 完成描述统计、聚类、回归和空间分析。
4. 完成供需匹配与经营决策规则。
5. 再做 Streamlit 界面和报告/图表交付。

## 6. 验收原则

- 原始文件只读保留。
- 任何统计结果必须由代码生成。
- Google Trends 使用真实导出文件，并在分析中说明独立归一化口径。
- 模型指标必须来自独立测试集。
- 供需指数是研究性相对指标，不解释为投资回报率。
- 跨城市结果优先使用结构占比和标准化指标，不直接比较原始数量。
